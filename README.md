# AI-Based Exam Proctoring System

An AI-powered web application designed to demonstrate online examination monitoring using face verification and object detection.

## Features

- Face detection and verification
- Webcam-based monitoring
- Phone and object detection
- Exam timer and interactive quizzes
- Violation tracking and suspicion scoring
- Student and administrator dashboards
- Exam reports and result generation

## Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- BlazeFace
- COCO-SSD

## Live Demo

[Try the Live Project](https://srilakshmin249.github.io/ai-based-proctoring-system/)

## Project Overview

This project explores how browser-based computer vision can support online examination monitoring. It combines a web interface with face detection, object detection, and examination features.

**Note:** This is a demonstration project. Detection results may be inaccurate, and the current browser-based implementation does not provide secure, centralized monitoring across devices.

## Future Improvements

- Backend integration for centralized exam management
- Secure authentication and data storage
- Improved detection accuracy and violation review
- Support for multi-device examination sessions
